---
version: 0.1.2
title: Dia joins in
---

- **Dia.** Ladle now sets up its connection for Dia, so the extension loaded in Dia hands downloads over the way it does in Chrome, Arc, Edge and Brave. The Terminal installer and the docs know Dia too. If you added Dia’s connection file by hand, Ladle takes it over from here.
- **The catch panel names the right browser.** It now takes the name from the browser that started Ladle’s helper, so Arc, Dia and Brave are no longer called Chrome.
