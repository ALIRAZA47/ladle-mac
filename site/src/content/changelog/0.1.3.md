---
version: 0.1.3
title: Ready for the store
---

- **The Chrome Web Store copy connects.** Ladle now recognises the extension when it’s installed from the Chrome Web Store, so it hands downloads over just like the developer-mode copy. The listing is under review; the developer-mode zip stays with every release in the meantime.
- **A second security pass**, this time over the whole app, the installer and the release pipeline:
  - Cookies that arrive with a download are forgotten the moment it finishes, older lists are cleaned up at launch, and Ladle’s own files can be read by your account only.
  - The extension passes a site’s strict-mode cookies only when the download comes from the page’s own site, as the browser itself would.
  - The Terminal installer checks the download’s size and signature against the update key built into Ladle before it installs anything.
  - Ladle and its browser helper talk over a private socket and check each other’s identity, so another program can’t pose as either of them.
  - Playlists and servers that report impossible sizes, lengths or ranges are refused instead of tripping Ladle up, and a download that keeps failing at launch is marked failed rather than retried forever.
  - A web page’s `ladle://` link can no longer vouch for its own checksum, and file names drop invisible characters that could disguise a file’s type.
- **Releases** can only be started by the repository’s owner, from code that went through `main`.
