## In Ladle

| Keys | What it does |
| --- | --- |
| <kbd>⌘N</kbd> | Add downloads |
| <kbd>⌘K</kbd> | Paste a link or search |
| <kbd>Space</kbd> | Pause or resume the selected download |
| <kbd>⌥⌘P</kbd> | Pause or resume all |
| <kbd>⌘R</kbd> | Retry the selected download |
| <kbd>⌘O</kbd> | Open the selected file |
| <kbd>⇧⌘R</kbd> | Show in Finder |
| <kbd>⌘⌫</kbd> | Remove from list (the file stays) |
| <kbd>⌘,</kbd> | Settings |

## In your browser

| Keys | What it does |
| --- | --- |
| Hold <kbd>⌥ Option</kbd> while clicking a link | Let the browser download it instead of Ladle, just that once |

## Reading the symbols

| Symbol | Key |
| --- | --- |
| ⌘ | Command |
| ⌥ | Option |
| ⇧ | Shift |
| ⌫ | Delete |
