---
title: Duplicate file names
description: When a file with the same name is already in the folder, Ladle keeps both out of the box. You can have it replace the old file or ask you instead.
---

## Choose what happens

Open **Ladle › Settings › Downloads** and set **If a file with the same name exists**:

| Choice | What Ladle does |
| --- | --- |
| **Keep both** | Saves the new file with a number added, like Finder does: `report.pdf` becomes `report 2.pdf`, then `report 3.pdf`. This is the default. |
| **Replace** | The new file takes the old one’s place. |
| **Ask** | Asks you each time, so you can decide file by file. |

Pick **Ask** if you sometimes re-download a file on purpose and sometimes don’t.

## Downloading the same link twice

This setting is about file names in the folder. Ladle also remembers which links you’ve downloaded: when you paste a list in the Add sheet, links you already have are marked **Already downloaded** and left unchecked. See [Many links and numbered series](/docs/adding-downloads/many-links/).
