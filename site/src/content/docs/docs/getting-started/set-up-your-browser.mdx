## Add the extension

<Tabs syncKey="browser">
<TabItem label="Safari">

<TabAnchor id="safari" />

Ladle’s Safari extension can’t run for now. Safari only loads extensions from apps signed by a registered Apple developer, and Ladle is made without a paid Apple developer account. That’s also why macOS asks you to approve Ladle on its [first launch](/docs/getting-started/install/#first-launch). **Ladle › Settings › Browsers** says the same.

Ladle still works with Safari. Instead of clicking the download:

- **Copy the link.** Right-click the download link and choose **Copy Link**. When you switch to Ladle or open its menu bar menu, it offers to download it.
- **Drag the link** onto Ladle’s window or its Dock icon.
- **Paste the link** into the bar at the top of Ladle’s window. Press <kbd>⌘K</kbd> to jump there.

</TabItem>
<TabItem label="Chrome, Arc, Edge and Brave">

<TabAnchor id="chrome" />

<UnlessStore browser="chrome">

Ladle’s extension is on its way to the Chrome Web Store. Until it’s there, you can add an early-access copy in developer mode: the same extension, loaded from a folder on your Mac instead of the store. Arc, Dia, Edge and Brave use it too.

<Steps>

1. Download <a href={CHROME_EXTENSION_ZIP_URL}>`Ladle-Chrome-Extension.zip`</a> from Ladle’s latest release, then double-click it to unzip it. Keep the **Ladle-Chrome-Extension** folder you get, because your browser loads the extension from there.

2. Open your browser’s extensions page by typing its address into the address bar: `chrome://extensions` in Chrome, `arc://extensions` in Arc, `dia://extensions` in Dia, `edge://extensions` in Edge or `brave://extensions` in Brave.

3. Turn on **Developer mode**.

4. Click **Load unpacked**, then choose the **Ladle-Chrome-Extension** folder.

5. Keep Ladle in your Applications folder and open it once, so the extension can reach it.

</Steps>

{/* Screenshot: the extensions page with Developer mode on and Ladle loaded. */}

<Aside type="tip" title="Let Terminal do steps 1 and 2">
This command downloads the extension into place, opens your browser’s extensions page and copies the folder’s path. Then turn on **Developer mode**, click **Load unpacked**, press <kbd>⌘⇧G</kbd> and paste the path. To update the extension later, run the command again and click the reload button on Ladle’s card. [More about the script](/docs/getting-started/install/#install-from-terminal).

```sh
curl -fsSL https://ladle.alirazakhan.me/install.sh | bash -s -- --extension-only
```

</Aside>

Your browser may remind you now and then that developer-mode extensions are on, and offer to turn them off. That’s expected for an early-access copy; keep Ladle’s on, or it stops catching downloads. This copy doesn’t update itself either: for a newer one, remove Ladle on the extensions page and repeat these steps.

When Ladle is in the Chrome Web Store, the link will be right here, and the store version, which keeps itself up to date, replaces this copy.

Rather not use developer mode? Copy, drag or paste links instead, as described in [Using another browser](#using-another-browser).

</UnlessStore>

<IfStore browser="chrome">

<Steps>

1. In Ladle, choose **Ladle › Settings**, click **Browsers**, then click **Get extension** next to Chrome, Arc, Edge and Brave. Or use the button below.

2. On the Chrome Web Store page, click the button to add Ladle to your browser, then confirm.

3. Keep Ladle in your Applications folder and open it once, so the extension can reach it.

</Steps>

<StoreButton browser="chrome" />

Arc, Dia, Edge and Brave use the same extension as Chrome. In Edge, turn on **Allow extensions from other stores** when Edge asks.

**Using the early-access copy?** Remove it on your browser’s extensions page before you add Ladle from the store. Afterwards, you can turn off **Developer mode** and move the **Ladle-Chrome-Extension** folder to the Trash.

## Check that it works

Click a download link for a file type Ladle catches, like a `.dmg` or `.zip`. Ladle shows its catch panel with the file’s name, size and where it will be saved.

<CatchPanel />

- **Download** starts it right away.
- **Later** adds it to your list in Ladle without starting it.
- **Let the browser handle it** hands the file back to your browser, just this once.
- **Always download .dmg files without asking** (it names the file’s type) skips the panel for that type from now on.

Rather never see the panel? Turn off **Ask before downloading** in **Ladle › Settings › Browsers**, and Ladle starts every download it catches straight away.

## If downloads still open in the browser

- Check that the extension is turned on, then quit and reopen the browser.
- Ladle only catches the file types listed under **Catch these file types** in **Ladle › Settings › Browsers**. Out of the box that’s dmg, pkg, zip, iso, mp4, mov, mkv, mp3, flac and pdf. Click **Edit…** to add the type you need.
- Some sites start downloads from a script instead of a link. Copy the link, and Ladle offers to grab it.

Still stuck? Read [The browser isn’t handing off downloads](/docs/fixing-problems/browser-not-handing-off/).

## Using another browser

Ladle doesn’t need an extension to download a link. In any browser, copy a download link and Ladle offers to grab it the next time you switch to it or open its menu bar menu. You can always paste the link into Ladle’s window too. You’ll see this listed as **Everything else** in **Ladle › Settings › Browsers**.
